              📥 Two source files — every week

              • File 1 — Past week's DHL report (already validated). For WK23 this is DMAL_May26_ReferencekeyRepor.xlsx. Contains WK22 shipments with IP columns already filled. Carried forward as-is — no re-validation.Must have a Week Number or Month/Week column · Sheet: DMAL or Shipment Data
              • File 2 — Current week raw p44 export. Fresh 53-col export for the new week only. Dashboard validates all 5 ref keys from scratch, assigns ISO week label, filters to DMAL AIR + OCEAN.Same format as monthly raw file · CONTAINER_ID auto-removed · HOUSE_AIR_WAYBILL → AIR

              📤 What gets generated

              • Shipment Data. All rows from both weeks combined, IP columns colour-coded green/amber/red. Week Number column shows 2026-WK{N}.
              • Chart_Data. Rolling pivot table: Reference Key × Mode × Week → Total Shipments / Info Provided Count / Performance %.
              • AIR sheet & OCEAN sheet. 5 combo charts each. Green bars = Performance % (left axis, 0–100%). Blue line + circle markers = Number of Shipments (right axis). Data labels on both series.Hard values in hidden scratch columns ensure charts always render
